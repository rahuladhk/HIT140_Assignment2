"wc2026_efi.csv" is the RAW data file

"Discilpine_csv.py" is python code that formats the data from RAW csv file
to "FIFA_2026_Discipline.csv" with only required column

Finally "Discipline_Compare.py" reads "FIFA_2026_Discipline.csv" and
compares all the data to check Numbers of Yellow card Defenders and Forward
players got.
